# site-skills

Скіли для Claude Code, з якими сайти виходять живими, молодіжними і «як застосунок» на телефоні, а не шаблонним AI-лендінгом.

## Що всередині

| Скіл | Що дає | Звідки |
|---|---|---|
| `youth-site-vibe` | Концепт-метафора замість шаблону, маленька палітра, пружинні анімації («кинули і приліпили»), нативне відчуття на телефоні, дії без очікування. Витяг із того, як зроблено [gimmie](https://gimmie.gift). | свій |
| `design-taste-frontend` | Анти-шаблонні правила для лендінгів і портфоліо: композиція, шрифти, що заборонено (типові AI-кліше), перевірка перед здачею. | [tasteskill](https://github.com/Leonxlnx) by Leonxlnx, MIT |
| `frontend-design` | Офіційна скіл Anthropic: обрати сміливий естетичний напрям, типографіка, не «дефолтний» вигляд. | [anthropics/skills](https://github.com/anthropics/skills), Apache 2.0 |

Ще варто глянути: [transitions.dev](https://transitions.dev), 21 готовий CSS-перехід (дропдаун, модалка, таби, успіх-галочка).

## Як поставити

```bash
git clone https://github.com/revutastohnu/site-skills.git
mkdir -p ~/.claude/skills
cp -R site-skills/skills/* ~/.claude/skills/
```

Перезапусти Claude Code. Далі просто пиши як звичайно: «зроби сайт для нашої тусовки, щоб було молодіжно і з анімаціями», скіли підхопляться самі.

## Як отримати найкращий результат

- Спершу скажи, **що це за річ у реальному світі** (стіна з постерами, зін, шафка, дошка з наліпками). Від цього все інше.
- Давай реальний контент: фото, тексти, назви. Без цього навіть найкращий дизайн виглядає порожнім.
- Дивись результат **з телефона**: більшість людей прийде з Instagram / TikTok.
- Правки пиши конкретно: «наліпки хай падають повільніше», «рожевий лише на кнопці».
